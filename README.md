# IASD Studio

Central audiovisual para a igreja, sem Lovable. Aplicação estática em HTML, CSS e JavaScript.

## Uso
Abra `index.html` ou publique o repositório no Vercel como projeto estático (framework: Other, sem build, output: raiz).

## Primeira versão
Painel e segunda tela (BroadcastChannel), cronograma, escalas, datas especiais, sorteio de pessoas e números, player de mídia local e projeção de versículos digitados. Cronograma e escalas ficam no armazenamento local do navegador; arquivos de mídia não são enviados nem persistidos. Para controle entre aparelhos, login e biblioteca compartilhada será necessário configurar backend. Use apenas músicas e textos com direitos de uso.

## Privacidade
O repositório está público. Não inclua dados pessoais reais nem arquivos protegidos no código-fonte. Nenhuma senha ou token deve ser salvo no repositório.
