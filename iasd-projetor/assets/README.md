Logo do programa:
- `logo.png` (256×256) é a imagem mostrada dentro do painel (menu lateral, banner, tela vazia, Sobre). Para trocar a logo no painel, substitua este arquivo mantendo o nome.
- `iasd-app.ico` é o ícone do Windows (janela, bandeja, instalador). Para trocá-lo, gere um .ico com os tamanhos 16, 32, 48, 64, 128 e 256.
